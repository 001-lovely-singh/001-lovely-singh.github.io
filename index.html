Play RPG Maker and Ren'Py games on your phone

Grab a blanket, pick a game, and settle in. Any Play is a free Android app that runs RPG Maker MV/MZ games right away, and Ren'Py and RPG Maker XP/VX/VX Ace games through small plugins. Works offline. No PC needed.

Plugins for more engines

Some games can't run inside a web view, so Any Play hands them to a small plugin app. Install a plugin once and Any Play opens your game with it automatically. Your game files are never copied or changed. You can install, update or remove plugins from the puzzle-piece icon at the top of the app.

Install in a few steps

  1. Download the APK from the button below.
  2. If Android asks, allow installs from unknown sources for your browser or file manager.
  3. Open Any Play and tap Add a new game or Unpack a game.
  4. Pick your game folder (or .zip) and start playing.
  5. For Ren'Py PC or RPG Maker XP/VX/VX Ace games, install the matching plugin from the Plugins section first.

Any Play does not include any games. Bring your own.
